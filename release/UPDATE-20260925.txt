tg-signer Dashboard 1.1.0 更新（2026-09-25）

更新内容：
- 发布单容器 Docker 镜像和 Linux amd64 VPS 完整部署包。
- 签到任务列表支持 20/50/100 条分页、跨页搜索、排序和删除后的页码修正。
- 搜索支持任务名、Bot 用户名、配置中保存的目标名称以及数字或字符串 Chat ID。
- 默认 Docker 端口绑定收紧为 127.0.0.1:8999；公网部署请使用 HTTPS 反向代理。
- 新增发布安装说明、根目录许可证、变更日志和 GitHub Actions CI。

验证范围：
- 后端 pytest 与固定上游 pytest
- Ruff 静态检查
- 前端 TypeScript 类型检查与 Next.js 生产构建
- Docker 镜像健康检查

真实 Telegram 登录、发信、AI 识别和外部通知需要使用者自己的凭据与网络环境，未在发布过程中向外部账号发送测试消息。
