TG-SIGNER 2.0.0 更新说明（2026-11-18）

网页完全重做：顶部导航、电蓝控制中心、轨道与光场动效、数据带、执行队列、时间线、全新登录页和任务编辑侧面板。
持续动效可暂停并记住偏好；尊重系统减少动态效果。新增任务状态筛选，保留已有签到、自动化、监控与日志功能。
主题支持系统自动切换、手动覆盖和跨标签页同步，趋势图按需加载。
账号、任务、会话、调度与日志 API 保持兼容，无需数据库迁移。

镜像：ghcr.io/dongbo501/tg-signer:2.0.0
架构：linux/amd64、linux/arm64
latest 在镜像健康验证后同步更新。

升级步骤：
1. 按 README 备份 data 目录。
2. 使用发布附件的 docker-compose.yml；已有配置保留端口、数据目录和环境参数，
   将 image 改为 ghcr.io/dongbo501/tg-signer:2.0.0。
3. docker compose pull
4. docker compose up -d --wait
5. 浏览器刷新页面并核对账号、任务、主题和动效开关。

回退：将镜像改回 ghcr.io/dongbo501/tg-signer:1.2.1 后重新拉取启动。
