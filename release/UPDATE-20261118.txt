TG-SIGNER 1.3.0 更新说明（2026-11-18）

本版本重构网页的主题、响应式布局、移动导航、表格和表单。
主题支持系统自动切换、手动覆盖和跨标签页同步，趋势图按需加载。
账号、任务、会话、调度与日志 API 保持兼容，不需要数据库迁移。

镜像：ghcr.io/dongbo501/tg-signer:1.3.0
架构：linux/amd64、linux/arm64
latest 标签在容器健康与关闭检查通过后同步更新。

升级步骤：
1. 按项目备份说明备份 data 目录。
2. 使用发布附件的 docker-compose.yml；已有配置请保留端口、数据目录和环境参数，
   将 image 改为 ghcr.io/dongbo501/tg-signer:1.3.0。
3. docker compose pull
4. docker compose up -d --wait
5. 浏览器刷新页面；确认账号和任务仍在，检查主题和导航。

回退：将镜像改回 ghcr.io/dongbo501/tg-signer:1.2.1 后重新拉取并启动。
源码包、固定版本 Compose、安装说明和 SHA256SUMS 由 GitHub Release 提供。
