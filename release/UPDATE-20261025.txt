TG-SIGNER 1.2.1 更新说明（2026-10-25）
====================================

健康账号改为每 5 分钟验证一次连接。
每次断线最多自动重连 3 次；首次发现断线的检查不计入重连次数。
连续失败 3 次后停止自动尝试，后台巡检和任务执行均不能绕过上限。
请检查网络/代理后在面板手动刷新连接，或重新登录；连接验证成功后计数清零。
计数保存在内存中，服务重启也会重新开始。Telegram FloodWait 的等待时间优先。
重连保留监听器和工作器，不重新执行 startup 规则或重发可能已送达的消息。
会话失效或封禁仍需人工重新登录。

镜像：ghcr.io/dongbo501/tg-signer:1.2.1
架构：linux/amd64、linux/arm64
latest 标签同步指向本版本；发布附件的 docker-compose.yml 固定使用 1.2.1。

更新步骤：
1. 完整备份 data 目录，同时保留数据库、encryption.key 和 jwt.key。
2. 保留现有端口、挂载、时区和代理设置；使用固定版本时将 image 改为
   ghcr.io/dongbo501/tg-signer:1.2.1。
3. 执行：
     docker compose pull
     docker compose up -d --wait
4. 登录面板检查账号状态；超过重试上限的账号会在日志中提示手动恢复。

源码归档和部署附件可通过 SHA256SUMS 校验。
发布测试使用模拟 Telegram 响应，不包含真实账号或任何密钥。
